## Four Beats

1. **Name the set.** Give the PDQ Inventory Enterprise own PCs a short title before you trust a one-off export.
2. **Pin the live machines.** Keep current hardware on PDQ Inventory Enterprise hardware scan and leave unused sets aside.
3. **Read the software.** Open PDQ Inventory Enterprise software list only for machines and folders the reader is authorized to run.
4. **Check the views.** Read PDQ Inventory Enterprise collection views before you archive a machine.
5. **Keep the pair.** Leave the scan and the list on the same PDQ Inventory Enterprise own PCs.
6. **Leave the views ready.** Keep collection views aligned with PDQ Inventory Enterprise hardware scan.
7. **Read the set again.** Open PDQ Inventory Enterprise software list if the machine list still looks crowded.
8. **Close the loop.** Clear finished machines so the next PDQ Inventory Enterprise visit does not start with a search.

## First Questions

**Does PDQ Inventory Enterprise replace every other program?**
No. PDQ Inventory Enterprise sits beside the ticket desk, browser, and lists you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate PDQ Inventory Enterprise profile.

**What should a new user try first?**
One small PDQ Inventory Enterprise hardware scan today, then the same collection views tomorrow.

**Do collection views leave the own PCs?**
No. PDQ Inventory Enterprise collection views stay with PDQ Inventory Enterprise software list on that set.

**Which machines belong in this scan?**
Only machines and folders the reader is authorized to run. PDQ Inventory Enterprise inventories PCs you administer, not a fleet you do not own.

**Is PDQ Inventory Enterprise only for a finished export?**
No. PDQ Inventory Enterprise can hold a single machine while the rest of the office stays off the board.

**Will the next admin still see the software list?**
Yes. A named PDQ Inventory Enterprise own PCs set keeps hardware attached to the views.

**Does the software list need a second export?**
No. PDQ Inventory Enterprise keeps the hardware scan and the software list on these own PCs.

## Field Note

PDQ Inventory Enterprise is easier to trust when the own PCs stay smaller than the folder they came from. A named set shows what is active, the scan pins show which machine you will read today, and the closing note tells the next admin which title changed.

Keep that inventory on machines and folders the reader is authorized to run. Collection views are a desk record for PCs you administer, not a one-off export of a fleet you do not own.

## One Real Pass

Pick a set that already has a name. Open it in PDQ Inventory Enterprise, keep only authorized machines on the scan, and finish one collection view you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different desk and leave it out of these PDQ Inventory Enterprise own PCs.
